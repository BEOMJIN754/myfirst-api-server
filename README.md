# My First API Server

첫 API 서버를 만들며 개발 과정을 기록하는 프로젝트입니다.

## 현재 상태

프로젝트 초기 설정 단계입니다. 현재 저장소에는 이 README만 있으며, 서버 코드와 실행 설정은 아직 추가되지 않았습니다.

## 시작하기

Git이 설치된 환경에서 저장소를 복제합니다.

```bash
git clone https://github.com/BEOMJIN754/myfirst-api-server.git
cd myfirst-api-server
```

서버 실행 방법은 코드와 개발 환경이 정해진 뒤 안내할 예정입니다.
